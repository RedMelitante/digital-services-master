DIGITAL SERVICES MASTER — WEBSITE DESIGN (47 pages)
Exported from the Claude Design file on 12 November 2026.

HOW TO VIEW
Open index.html in any browser. It opens the homepage, and every link in the
header, footer and buttons goes to the other pages, all offline.

WHAT'S INSIDE
  index.html     Opens the homepage (pages/Main.html).
  pages/         The 47 pages as plain HTML you can open and click through.
                 These are snapshots, so interactive parts (phone menu, FAQ
                 toggles, pricing tabs, "Jump to section" on phones) are shown
                 in their default state. Hover dropdowns in the header still work.
  images/        Every image used in the design (logos, client sites, clinic
                 photos, blog pictures).
  screenshots/   A full-page picture of each page, numbered in canvas order.
  source/        The original Claude Design page files (.dc.html) and
                 canvas.json, with image paths pointing to ../images/.
                 Use these as the reference when building the site in Astro.
